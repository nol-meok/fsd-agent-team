# 음식점 리뷰 작성 기능

## 1. 개요
- 작업 유형: feature
- 요청 사항: 사용자가 음식점에 대한 리뷰(별점 + 텍스트)를 작성하고 제출할 수 있는 기능
- 영향 범위: entities, features, widgets, app
- 사용자 결정 사항:
  - 상태 관리 방식: **React Query** (React Query / Zustand / useState)
  - 별점 UI 방식: **5점 클릭** (5점 클릭 / 10점 슬라이더 / 이모지 선택)
  - 리뷰 최소 글자수: **10자** (10자 / 20자 / 제한 없음)

## 2. 현재 상태 분석
- 프로젝트: Next.js 16 + TypeScript + FSD 아키텍처
- 현재 entities, features 폴더 비어있음 (첫 기능 개발)
- widgets에 home-hero만 존재
- shared/config/globals.scss, shared/ui/ 비어있음

## 4. 작업 순서
1. **entities** - Restaurant 타입, Review 타입 + API + React Query 훅
2. **features** - WriteReviewForm + 유효성 검사 + mutation
3. **widgets** - ReviewFeed (목록 + 폼 조합)
4. **app** - /reviews 페이지 라우팅
